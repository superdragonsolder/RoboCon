## 🔄 算法流程

```
┌─────────────────────────────────────────┐
│      1. 创建梅花桩网格模型              │
│         ↓                               │
│      2. 随机生成KFS分布                 │
│         ↓                               │
│      3. 初始化BFS路径规划器             │
│         ↓                               │
│      4. 搜索最优路径                    │
│         ├─ 状态: (位置, 已收集掩码)     │
│         ├─ 约束: 避开假方块             │
│         └─ 目标: 收集所有R2到达出口     │
│         ↓                               │
│      5. 重建完整路径                    │
│         ↓                               │
│      6. 导航到梅林入口                  │
│         ↓                               │
│      7. 逐步执行路径                    │
│         ├─ 移动: W/A/S/D                │
│         ├─ 检测: 相邻R2                 │
│         ├─ 收集: 机械臂夹取             │
│         └─ 记录: 详细日志               │
│         ↓                               │
│      8. 完成梅林阶段                    │
└─────────────────────────────────────────┘
```
