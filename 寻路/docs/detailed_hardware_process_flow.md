# R2 决策系统 - 硬件集成详细流程指南

## 概述

本文档说明 R2 决策系统如何与硬件系统深度集成，提供从启动到结束的完整、详细的中文日志输出。

## 完整流程结构

```
┌─────────────────────────────────────────────────────┐
│           【启动】                                   │
│  • 检查传感器状态（激光/相机/底盘/机械臂）          │
│  • 执行系统校准（前进/旋转/机械臂回零）             │
│  • 确定启动模式（冷启动/补武器/补KFS）              │
└────────────────┬────────────────────────────────────┘
                 ↓
┌─────────────────────────────────────────────────────┐
│           【武馆】                                   │
│  • 旋转搜索 → 检查激光距离找到端头位置              │
│  • 底盘前进 → 移动到武器架旁                        │
│  • 机械臂动作 → 打开/移动/闭合（抓取）              │
│  • QR码扫描 → 识别二维码进行配对                    │
│  • 组装等待 → 等待R1准备，执行最终组装              │
└────────────────┬────────────────────────────────────┘
                 ↓
┌─────────────────────────────────────────────────────┐
│           【梅林】                                   │
│  • 规则保护 → 检查是否触犯夹取规则                  │
│  • 导航移动 → 底盘前进至梅林区域                    │
│  • 视觉扫描 → 使用双目相机检测KFS位置              │
│  • 九宫格策略 → 选择最优夹取目标                    │
│  • 机械臂夹取 → 打开/靠近/闭合进行夹取              │
└────────────────┬────────────────────────────────────┘
                 ↓
┌─────────────────────────────────────────────────────┐
│           【对抗区】                                 │
│  • 底盘导航 → 移动进入对抗区                        │
│  • 策略执行 → 先阻断后成线                          │
│  • 机械臂放置 → 定位并释放KFS方块                   │
│  • 赢线形成 → 获得比赛胜利                          │
└────────────────┬────────────────────────────────────┘
                 ↓
┌─────────────────────────────────────────────────────┐
│           【结束】                                   │
│  • 硬件安全关闭                                      │
│  • 输出最终统计                                      │
└─────────────────────────────────────────────────────┘
```

## 各阶段详细的硬件操作

### 1. 启动阶段（LAUNCH）

```
[启动] ========== 启动阶段开始 ==========
[启动] 选择启动模式: 冷启动
[启动] 检查启动条件...
[启动] → 检查传感器状态
[启动]   ✓ 激光测距仪就绪 (前:101cm)
       └─ 调用：laser->update(); laser->get_data()
[启动]   ✓ 单目相机就绪
       └─ 调用：mono_camera->update(); is_ready()
[启动]   ✓ 底盘控制器就绪
       └─ 调用：chassis->is_ready()
[启动]   ✓ 机械臂就绪
       └─ 调用：arm->is_ready()
[启动] 执行启动校准...
[启动] → 执行启动校准
[启动]   动作1: 前进测试
       └─ 调用：chassis->set_velocity(0.2, 0, 0); sleep(300ms)
[启动]   动作2: 原地旋转测试
       └─ 调用：chassis->set_velocity(0, 0, 0.5); sleep(300ms)
[启动]   动作3: 停止
       └─ 调用：chassis->stop()
[启动]   动作4: 机械臂回零位
       └─ 调用：arm->move_to_joint_angles([0, -π, 0]); 
              arm->gripper_open(); arm->wait_for_completion(2s)
```

**核心硬件操作**：
- 激光测距仪：确保传感器就绪，读取当前距离
- 底盘：前进 → 旋转 → 停止（验证可操作性）
- 机械臂：回零位 + 打开夹爪（为下一阶段准备）

### 2. 武馆阶段（MC）

```
[武馆] ========== 武馆阶段开始 ==========
[武馆] 目标: 取得端头并与R1协作组装

【子步骤1：旋转搜索端头】
[武馆] → 第1步: 旋转寻找端头位置
[武馆]   → 执行旋转搜索
[武馆]     旋转 90度，检查距离
       └─ 调用：chassis->set_velocity(0, 0, 0.5);
              laser->update();
              float dist = laser->get_data().front_distance
[武馆]     前方距离: 103cm
[武馆]     旋转 180度，检查距离
[武馆]     前方距离: 105cm
[武馆]     旋转 270度，检查距离
[武馆]     前方距离: 107cm

【子步骤2：移动到武器架】
[武馆] → 第2步: 移动靠近武器架
[武馆]   → 移动到武器架
[武馆]     前进移动...
       └─ 调用：chassis->set_velocity(0.3, 0, 0);
              sleep(3000ms); chassis->stop()

【子步骤3：使用机械臂抓取端头】
[武馆] → 第3步: 使用机械臂抓取端头
[武馆]     动作: 打开夹爪
       └─ 调用：arm->gripper_open()
[武馆]     移动到抓取位置 (0.4m, 0m, 0.15m)
       └─ 调用：arm->move_to_pose(0.4, 0, 0.15, 0, 0, 0);
              arm->wait_for_completion(0.5s)
[武馆]     闭合夹爪
       └─ 调用：arm->gripper_close(); sleep(200ms)
[武馆]     夹爪状态: 成功抓取
       └─ 调用：arm->get_feedback().gripper_open ? 失败 : 成功

【子步骤4：QR码识别与组装】
[武馆] → 第4步: 扫描QR码并配合组装
[武馆]     扫描QR码...
       └─ 调用：qr_scanner->update();
              auto result = qr_scanner->scan()
[武馆]     识别到二维码: R2_001_MC_01
       └─ 如果 result.detected → 成功；否则重试
[武馆]     等待R1完成部分组装...
       └─ sleep(500ms)
[武馆]     R1已准备好，执行最终组装
       └─ sleep(200ms)
```

**核心硬件操作**：
- 底盘：旋转扫描（循环360度，每90度检查一次距离）
- 激光传感器：每旋转后读取前方距离
- 底盘：前进至目标位置
- 机械臂：多步骤动作（打开 → 移动 → 闭合 → 反馈）
- 二维码扫描器：识别组装对应的二维码

### 3. 梅林阶段（MF）

```
[梅林] ========== 梅林阶段开始 ==========
[梅林] 目标: 在梅林区域寻找并夹取KFS

【子步骤1：导航到梅林区域】
[梅林] → 第1步: 导航到梅林区域
[梅林]   → 计划路径到 (2,4) 梅林入口
[梅林]     移动...
       └─ 调用：chassis->set_velocity(0.25, 0, 0);
              sleep(4000ms); chassis->stop()
[梅林]     到达梅林区域

【子步骤2：视觉扫描KFS】
[梅林] → 第2步: 扫描并靠近KFS
[梅林]   → 使用相机扫描KFS
       └─ 调用：stereo_camera->update();
              auto result = stereo_camera->detect_and_depth("kfs")
[梅林]     检测到KFS @ 距离 50cm
       └─ 如果 result.detected
            输出："距离 ${result.depth*100}cm"
[梅林]   接近KFS并准备夹取

【子步骤3：九宫格策略与夹取】
[梅林] → 第3步: 收集KFS
[梅林]     使用九宫格策略选择最优目标
       └─ 创建 BoardState; 调用 choose_best_cell()
[梅林]     优先目标: 第1行第1列
[梅林]     打开夹爪
       └─ 调用：arm->gripper_open(); sleep(200ms)
[梅林]     移动到KFS位置
       └─ 调用：arm->move_to_pose(0.35, 0.05, 0.1, 0, 0, 0);
              arm->wait_for_completion(2s)
[梅林]     闭合夹爪抓取
       └─ 调用：arm->gripper_close(); sleep(300ms)
[梅林]     ✓ 成功抓取KFS
[梅林] 当前携带R2 KFS数量: 1
```

**核心硬件操作**：
- 底盘：缓速前进至梅林区域
- 双目相机：实时检测KFS物体并测量距离
- 机械臂：移动到检测位置后进行夹取
- 策略规划：根据九宫格算法选择最优目标

### 4. 对抗区阶段（CF）

```
[对抗区] ========== 对抗区阶段开始 ==========
[对抗区] 目标: 放置KFS并执行赢线或阻断策略

【子步骤1：进入对抗区】
[对抗区] → 第1步: 进入对抗区
[对抗区]   → 移动进入对抗区
[对抗区]     前进...
       └─ 调用：chassis->set_velocity(0.2, 0, 0);
              sleep(3000ms); chassis->stop()
[对抗区]     已入场

【子步骤2：执行放置策略】
[对抗区] → 第2步: 放置KFS
[对抗区]   执行放置策略: 先阻断后成线
[对抗区]   → 第一步: 放置阻断方块
[对抗区]     定位到阻断位置 (0.5, 0, 0.05)
       └─ 调用：arm->move_to_pose(0.5, 0, 0.05, 0, 0, 0);
              arm->wait_for_completion(2s)
[对抗区]     释放KFS
       └─ 调用：arm->gripper_open(); sleep(200ms)
[对抗区]     ✓ 阻断方块已放置
[对抗区]   → 第二步: 形成赢线
[对抗区]     ✓ 成功形成赢线，获得5分!
```

**核心硬件操作**：
- 底盘：慢速进入对抗区
- 机械臂：定位精确放置位置
- 机械臂夹爪：释放KFS方块

## 故障诊断

### 激光传感器无反应
- 检查距离值是否更新
- 验证 `laser->update()` 是否被调用
- 查看日志中的距离值是否在合理范围

### 机械臂不动
- 检查 `arm->is_ready()` 返回值
- 验证目标位置是否在工作范围内
- 查看夹爪反馈 (`get_feedback().gripper_open`)

### 相机检测失败
- 确保对象在相机视野范围内
- 检查照明条件
- 验证置信度阈值设置

### 底盘不响应
- 检查速度命令是否被正确设置
- 验证 `chassis->is_ready()` 返回值
- 检查是否调用了 `stop()` 命令
